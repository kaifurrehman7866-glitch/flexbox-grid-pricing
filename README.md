# Flexbox vs Grid — Pricing Section Playground

Ye project ek 3-column pricing section ko do tareeqon se banata hai:
1. **Flexbox** se
2. **CSS Grid** se

Dono responsive hain — 600px se neeche single column me stack ho jate hain.

## Kaise dekhein
`index.html` ko browser me open karein (ya VS Code me "Live Server" extension se run karein).
